The PowerShell command:
Get-Command python
Is used to find how and where the python command is being resolved in your system.

🔍 What It Tells You
When you run Get-Command python, PowerShell will show:

CommandType: Whether it's an application, alias, function, etc.
Name: The command name (python)
Version: If available
Source: Where it's coming from (e.g., WindowsApps, Anaconda, etc.)
Path: The full path to the executable being used


✅ Why It's Useful

Helps you identify which Python interpreter is being used when you type python.
Useful when you have multiple Python installations (e.g., Anaconda, Microsoft Store, python.org).
Helps troubleshoot version mismatch or PATH conflicts.

🧠 What Are -m, -c, --option in Python Commands?
These are command-line flags or options passed to the Python interpreter. Here's what the common ones do:

✅ Common Python Flags

-m            Run a Python module as a script                         python -m pip install numpy runs the pip module
-c            Run a Python command directly from the command line     python -c "print('Hello')"
--version     Show Python version                                     python --version
--help        Show help info for Python CLI                           python --help

🧠 What Are --option Flags?
These are long-form options used by many command-line tools (including pip, conda, etc.). Examples:

--upgrade: Upgrade a package
--user: Install package for current user only
--force-reinstall: Reinstall even if already installed

Example:
python -m pip install numpy --upgrade --userShow more lines

🔄 PowerShell vs CMD: What's the Difference?
Example:
In CMD:
dir

In PowerShell:
Get-ChildItem

Both can run Python, but PowerShell is more modern and flexible.
